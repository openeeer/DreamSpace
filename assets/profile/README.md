# Profile reference artwork

- `dream_sphere.png` (1254×1254, transparent alpha): glass-like indigo dream
  planet, lavender crescent, cloud texture and rim light. No text or UI.
- `profile_landscape.png` (1586×992): violet clouds, distant illuminated cliffs,
  rocky foreground on the right, subtle warm horizon. Faded in with a gradient
  mask toward the top edge.
- `more_than_dreams_ru.png` (1536×1024, transparent alpha): handwritten
  “Больше, чем сны” with a thin underline, glowing lavender ink.
  English counterpart (optional): `more_than_dreams_en.png`.

Profile detects these bundled files automatically and falls back to the existing
nebula artwork when any of them is missing.
