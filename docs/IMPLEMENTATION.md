# Реализация DreamSpace

## Принятые решения

- Русский UI по умолчанию, английский опционально; пользовательский текст и демо не переводятся при смене интерфейса.
- Android/iOS; Flutter 3.44.1, Codemagic для iOS.
- Riverpod 3, SQLite/Drift, go_router с отдельными navigator для вкладок.
- UUID, даты сна как calendar date, created/updated UTC.
- Один черновик в локальной базе; создание и редактирование используют один экран.
- Shared elements: одна typed-таблица для symbols/characters/places, уникальность по normalizedName + kind.
- Dream payload JSON + SQL date/created; связи нормализованы. Изображения — asset IDs.
- Основная область интерфейса максимум 860 logical pixels; описание ограничено общим layout.

## Метрики

- Серия: уникальные календарные даты, окончание сегодня или вчера.
- Повторяющийся символ: минимум два сна.
- Темы: процент среди записей с выбранной темой.
- Mood distribution: процент от всех записей периода, неизвестные отмечены отдельно.
- Demo создаётся один раз, удаление не вызывает повторную инициализацию.

## Карта

Рёбра: символ +3, место/персонаж +2, настроение +0.5. Указанное настроение сравнивается только с другим указанным настроением. Обзор ограничен 150 рёбрами и 100 последними узлами. Поиск в текстовом режиме доступен по всему дневнику. При выбранном сне отображаются все его связи в видимой подвыборке.

Начальная раскладка: детерминированная спираль + 70 ограниченных force-итераций. При обновлениях сохраняются существующие позиции. Изображения и обводка узлов — Flutter widgets, связи — CustomPainter, камера — InteractiveViewer. Миниатюра Home показывает те же реальные совпадения в компактной компоновке.

## Состояние художественной части

Шрифты, космический фон, восемь иллюстраций и прозрачный пользовательский туман подключены. PNG-мастеры сохранены; runtime использует WebP. Туман анимируется общим контроллером фона с поддержкой Reduce Motion. Брендовая иконка сгенерирована, применение к платформенным размерам ещё предстоит. Процедурные обложки остаются аварийным fallback. Промпты перечислены в ASSET_PROMPTS.md.

Сфера сохранения реализована как короткий overlay; точный перелёт к вкладке карты отложен до финального согласования layout. Mist — рабочая базовая тема; финальную проверку контраста композиции нужно провести после добавления artwork.

## Дальнейшее развитие
