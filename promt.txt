Нужно разработать мобильное приложение **DreamSpace** на **Flutter**.

Это университетский проект, поэтому приложение должно быть не просто функциональным, а производить сильное визуальное впечатление. Нужен эффект «вау» за счёт дизайна, анимаций, плавности интерфейса и самой идеи.

Я приложу к этому заданию изображение с примером дизайна главного экрана. Используй его как главный визуальный референс.

ВАЖНО: НЕ НАЧИНАЙ СРАЗУ ПИСАТЬ ПРИЛОЖЕНИЕ.

Сначала полностью продумай:

* архитектуру приложения;
* список экранов;
* навигацию;
* модели данных;
* локальное хранение данных;
* структуру Flutter-проекта;
* переиспользуемые UI-компоненты;

Только после утверждения архитектуры и структуры можно переходить к написанию кода.

# 1. Концепция приложения

DreamSpace — это красивый персональный дневник снов.

Пользователь после пробуждения может записать свой сон, указать настроение, тип сна, персонажей, места, символы и другие детали.

Со временем приложение формирует визуальную «вселенную снов» пользователя.

Главная особенность приложения — не просто список текстовых записей, а визуализация повторяющихся образов, мест, персонажей и эмоций.

Например:

Пользователь несколько раз видел во сне:

* море;
* старый дом;
* неизвестного человека;
* лестницу;
* Луну.

Приложение показывает, что эти элементы встречались в нескольких снах и визуально связывает их между собой.

В итоге постепенно появляется красивая интерактивная карта снов.

---

# 2. Основной стиль приложения

Приложение пишем на Flutter, но визуально оно должно напоминать качественное современное приложение для iPhone.

Это НЕ должен быть стандартный Material Design.

Ориентироваться на:

* iOS;
* Apple Human Interface Guidelines;
* Liquid Glass;
* стеклянные панели;
* blur;
* translucency;
* мягкие световые эффекты;
* плавные переходы;
* минималистичные элементы управления.

При этом приложение не должно выглядеть как копия системного интерфейса iOS.

У DreamSpace должен быть собственный визуальный характер.

---

# 3. Визуальное направление

Основная тема:

**ночь / сон / космос / подсознание / мягкое свечение / туман / звёзды**

Основные цвета:

* очень тёмный синий;
* midnight blue;
* deep violet;
* indigo;
* мягкий lavender;
* холодный голубой;
* местами тёплый золотистый свет.

Фон не должен быть просто однотонным.

Желательно использовать:

* мягкие градиенты;
* звёздную пыль;
* туманности;
* медленные светящиеся частицы;
* лёгкий параллакс;
* едва заметное движение фона.

Главное — не перегрузить экран.

Интерфейс должен выглядеть дорого, спокойно и атмосферно.

---

# 4. Стеклянный интерфейс

Карточки и панели должны быть в стиле iOS glass UI:

* полупрозрачные поверхности;
* backdrop blur;
* мягкая светлая обводка;
* внутреннее свечение;
* очень мягкие тени;
* немного прозрачного синего/фиолетового оттенка.

Не использовать слишком толстые рамки.

Не превращать всё приложение в набор одинаковых прямоугольников.

У карточек может быть различная композиция.

Используй большие скругления.

---

# 5. Типографика

Интерфейс должен быть максимально близок к качественному iOS-приложению.

Основной системный шрифт желательно использовать похожий на San Francisco / SF Pro.

Если нельзя использовать SF Pro напрямую, выбрать очень близкий бесплатный аналог.

Для некоторых крупных заголовков можно использовать красивый serif-шрифт, чтобы создать более сказочную атмосферу.

Например:

DreamSpace

или название сна:

Moon Library

может использовать элегантный serif.

При этом:

* основной интерфейс;
* кнопки;
* подписи;
* настройки;

должны использовать аккуратный sans-serif.

# 11. Dream Map

Это один из главных wow-экранов приложения.

Нужна интерактивная карта.

Каждый сон представлен светящейся сферой.

Сны могут соединяться линиями.

Связь появляется, если у двух снов есть общий:

* персонаж;
* символ;
* место;
* настроение.

Например:

Dream A

содержит:

Moon

Ocean

Stranger

Dream B

содержит:

Moon

Forest

Dream C

содержит:

Ocean

House

Тогда карта визуально покажет связи.

---

Важно:

Карту нужно уметь:

* двигать пальцем;
* приближать;
* отдалять;
* нажимать на узлы.

При выборе сна остальные узлы могут немного затемняться.

Связанные — наоборот подсвечиваться.

---

Необходимо подумать, как технически реализовать карту во Flutter.

Возможно использовать:

CustomPainter

InteractiveViewer

Canvas

CustomPaint

AnimationController

или другой подход.

Но они должны быть спокойными.

* fade;
* scale;
* blur transitions;
* hero transitions;
* parallax;
* slow floating;
* glow;
* spring animations.

Например:

При добавлении сна новый узел появляется с небольшим свечением.
