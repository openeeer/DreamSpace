# DreamSpace

Локальный дневник снов на Flutter для Android и iOS. Русский интерфейс по умолчанию, английский включается в настройках.

## Запуск

Flutter **3.44.1**, Dart **3.12.1**.

```sh
flutter pub get
dart run build_runner build
flutter run
```

## Проверки и сборка

```sh
flutter analyze
flutter test
flutter build apk --debug
flutter build apk --release
```

Android APK: `build/app/outputs/flutter-apk/`.
Release Android пока подписывается debug-ключом для учебной установки; магазинная подпись настраивается отдельно.

## Реализовано

- Onboarding, Home, Journal, редактор и просмотр сна.
- Русский и английский UI, Midnight / Mist / System.
- SQLite через Drift, Riverpod, независимые вкладки go_router.
- Восемь русскоязычных демо-снов, однократное заполнение.
- Создание, редактирование, избранное, удаление, черновик.
- Настроение, тип, повторяемость, тема, яркость и осознанность.
- Общие символы, персонажи и места, переименование.
- Карта с pan/zoom, выбором узлов, фильтрами причин связи, текстовым списком.
- Календарь, статистика, серия записей.
- Утренние локальные уведомления, JSON / Markdown export.
- Анимации, уменьшение движения, плотные поверхности, haptics.
- Шрифты Lora и Inter доступны офлайн.

## Интерфейс iOS

Внутренние страницы используют `lib/core/internal_page.dart`: закреплённый serif-header
со стеклянными кнопками, панели, segmented controls, лавандовые switches и Cupertino sheets.
Система применена к настройкам, образам, наблюдениям, календарю, просмотру сна и редактору.
Время напоминания и дата записи выбираются через CupertinoDatePicker. Редактор сохраняет
черновик при системном возврате; «Готово» доступно после ввода описания. Share/delete — в меню сна.
`test/internal_pages_test.dart` проверяет настройки, picker, возврат редактора и адаптивность
при 200% текста. Снимки: `flutter test test/internal_pages_test.dart --dart-define=INTERNAL_CAPTURE=<existing directory>`.
Рукописная фраза настроек «Маленькие настройки — большие сны» подключена из
`assets/profile/settings_handwritten_ru.png`.
Первый запуск — три коротких экрана с лунной сферой, образами и созвездием снов.
Приветствие можно пропустить; завершение сохраняется локально. На широком экране
иллюстрация и текст располагаются рядом, крупный текст доступен через прокрутку.
`test/onboarding_test.dart` проверяет переходы, сохранение и размеры от 320×568;
`--dart-define=ONBOARDING_CAPTURE=<existing directory>` сохраняет три снимка.

Карта — отдельный pan/pinch canvas со стабильной раскладкой по ID и сохранением
координат/камеры в локальных настройках. Поиск учитывает название, текст и образы,
подсвечивает результаты и плавно центрирует камеру. Меню позволяет выбрать сильные
связи (два и более совпадения), сбросить положение/масштаб и прочитать объяснение.
Выбранный сон открывает компактную панель; долгое нажатие — Cupertino-меню.
Связи рисуются единым painter с исключением областей изображений и подписей.
`--dart-define=MAP_CAPTURE=<absolute PNG path>` сохраняет рендер карты в визуальном тесте.

Дневник использует компактные `DreamJournalCard` с предпросмотром, тегами, избранным
и Cupertino-меню (редактирование, отправка через системный share sheet, удаление).
Месяцы имеют полные названия, счётчики и сворачивание. Sliders в поиске открывает
сортировку по дате, выбор настроения и категории. Нижний отступ учитывает dock и safe area.
Для визуального сравнения дневника доступен `--dart-define=JOURNAL_CAPTURE=<absolute PNG path>`
при запуске `test/home_visual_test.dart`.

Главная перевёрстана по предоставленному референсу: растворённая в фоне библиотека,
карусель последних пяти снов, облачная CTA, настроения с реальными счётчиками,
цитата и компактные последние записи. Декоративные облака пропускают нажатия;
параллакс отключается при уменьшении движения. Прокрутка учитывает высоту dock и safe area.
`test/home_visual_test.dart` проверяет узкий экран, landscape, увеличенный текст и светлую тему;
`--dart-define=HOME_CAPTURE=<absolute PNG path>` сохраняет Flutter-рендер для сравнения.

Профиль «Мой мир» собран по референсу: dream sphere (`assets/profile/dream_sphere.png`),
рукописная надпись «Больше, чем сны», орбитальные звёзды, статистика с разделителями,
меню с подписями, цитата приватности и нижний пейзаж (`assets/profile/profile_landscape.png`).
Ассеты подключаются автоматически при наличии; без них используются существующие облака.
Для визуального сравнения доступен `--dart-define=PROFILE_CAPTURE=<absolute PNG path>`
при запуске `test/home_visual_test.dart`.

Нижняя навигация реализована через UIKit Platform View: настоящий `UIGlassEffect`
на iOS 26+, системный `UIBlurEffect` на предыдущих версиях. Сборке нужен **Xcode 26+**
(iOS 26 SDK). Reduce Transparency / Increase Contrast и настройка плотных поверхностей
переключают меню на непрозрачный системный фон. Выбор вкладки синхронизируется с go_router.
Нативные контролы используют SF Symbols и системные цвета.

Маршруты используют штатный `CupertinoPage`, который обновляет содержимое при
переключении веток go_router. Нативное меню явно получает жесты внутри своей области;
общий стеклянный фон не перехватывает взаимодействия кнопок.
Долгое нажатие на карточку открывает Cupertino action sheet: просмотр, избранное,
редактирование и карта. Поиск очищается одной кнопкой; клавиатура скрывается при
прокрутке. Редактор закрывается с сохранением черновика, включая запись только с названием.

Каждый открываемый экран имеет собственный непрозрачный космический фон; iOS-переход
и жест возврата больше не накладывают текст двух страниц друг на друга. Заголовок сна
и кнопка назад закреплены при чтении. Карта разводит узлы вместе с подписями;
кнопка сброса масштаба появляется только после zoom-жеста.

Нативный материал и его композицию поверх Flutter необходимо проверить на iPhone
с iOS 26: Windows-проверки не запускают UIKit и не подтверждают качество преломления.

## Ассеты приложения

**[Точные промпты и имена файлов](docs/ASSET_PROMPTS.md).**

Полный набор из восьми обложек, космического фона и прозрачного тумана подключён. Первые пять изображений и RGBA-туман предоставлены пользователем, остальные обложки сгенерированы через WaveSpeed. PNG-оригиналы сохранены, в приложение включаются только оптимизированные WebP. Туман медленно смещается и становится статичным при уменьшении движения.

Следующий визуальный этап: финальная корректировка кадрирования, применение готовой иконки к платформенным ресурсам и звуки. Звуковые файлы пока не включены.

## Архитектура

`lib/core` — дизайн и платформенные сервисы; `lib/data` — Drift/repository/providers; `lib/models` — доменные типы; `lib/features` — экраны и алгоритмы. Детали текущих решений: [IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

Сны хранят основные поля в JSON payload с индексируемыми SQL-полями даты/создания; элементы и связи нормализованы в отдельных таблицах. Это компактный MVP-вариант Drift, отличающийся от первоначально предложенной полностью нормализованной схемы. Счётчики и граф считаются из текущих данных, не захардкожены.

## Codemagic / iOS

Добавь проект в Git-репозиторий, подключи его к Codemagic и выбери workflow из `codemagic.yaml`.

- `android-demo`: анализ, тесты, APK.
- `ios-compile`: анализ, тесты, `DreamSpace-unsigned.ipa` для подписи в ESign.

Скачай `DreamSpace-unsigned.ipa` из артефактов сборки, импортируй в ESign, подпиши своим действующим сертификатом и совместимым provisioning profile, затем установи. IPA содержит `Payload/Runner.app`; Apple signing в CI для этого сценария не требуется. Для публикации в TestFlight потребуется отдельно настроить подпись и экспорт в CI.

На Windows iOS-сборка не выполняется. Реальная доставка уведомлений, iOS swipe/back, внешняя Share Sheet и GPU-плавность требуют проверки на устройствах.

## Bitrise

Репозиторий: https://github.com/openeeer/DreamSpace

1. Добавь приложение в Bitrise, подключив этот GitHub-репозиторий, ветка `main`.
2. Выбери конфигурацию из репозитория: **`bitrise.yml`** (а не сохранённую конфигурацию в редакторе Bitrise).
3. Выбери macOS stack с **Xcode 26+** для iOS; для Android подойдёт Android stack с Java 17 или новее.
4. Запусти нужный workflow:
   - `android-demo` — анализ, тесты и установочный `DreamSpace.apk`.
   - `ios-compile` — анализ, тесты и `DreamSpace-unsigned.ipa` для ESign.
   - `ios-simulator` — приложение для iOS Simulator без подписи.
5. Забери результат в **Apps & Artifacts** сборки.

Flutter 3.44.1 устанавливается workflow автоматически. Для перечисленных сборок Apple-сертификаты и WaveSpeed API-ключ не нужны. Для подписанного IPA/TestFlight потребуется отдельная настройка Apple signing в Bitrise.

Codemagic и Bitrise можно подключить к одному репозиторию одновременно. Автоматический запуск на push в `main` настрой в каждом сервисе; ручной запуск доступен сразу после подключения. Конфигурации в репозитории не создают подключения и webhooks автоматически.
